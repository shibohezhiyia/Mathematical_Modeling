# 网页数学图实验

首页“数学建模研究助手”下方展开 **数学图实验 · 开发搜索 / 冻结 / 留出审计**。这是一条独立的实验链路，不会替换原有研究结果、合并表格或调用模型 API。

## 从表格准备，不用写开发 JSON

在上方上传或处理表格，然后展开“从当前表格准备实验”：

1. 读取字段，明确选择 1–4 个数值输入和一个不同的目标。疑似编号不作为连续数值建议或自动执行输入；类别和日期字段需先明确转换方式。
2. 为每个字段选择单位。当前支持无量纲、计数、长度/时间/质量的部分常用单位、速度和开尔文；不支持未知单位、摄氏度等带偏移单位或任意自定义单位。未知不能填成无量纲。
3. 明确选择 12–360 行开发数据。系统先截取所选范围再转换数值，不扫描全表生成大数组；前 70% 训练、后 30% 开发检查。这个按当前行序划分的方式不证明时间、实体或近邻独立，也不代表全表分析。
4. 填写背景和数值容差。绝对容差使用目标的 SI 单位，相对容差 0.05 表示 5%，二者不是统计置信度。
5. 点击“准备实验（不运行）”，核对变量映射、单位换算和样本范围，再点击“运行通用搜索”。修改绑定设置后，旧准备结果和界面上的旧冻结入口失效，需要重新准备；历史产物不删除。

编译器生成 `bias + Σ aᵢxᵢ` 原语组合作为可执行搜索起点，自动推导系数量纲。数值先换算到 SI，参数搜索盒只用训练部分的尺度计算，并明确记录为工程搜索范围而非题面物理约束。重复输入、缺失/非有限数值和训练段常量输入会拒绝，不静默去重、插值或补零。

CSV、XLSX 或 Parquet 上传超过 50 MB 时，网页使用流式/row group 只读扫描建立最多 100,000 行的确定性覆盖表示，原始文件仍保存在本地。界面同时显示 `source_shape`、实际展示行数和 `bounded_representation`，并在证据中保留非完整数据标记。该表示只能用于探索和预览；纵向合并、跨表关联会拒绝受限预览，避免把样本误当成完整连接结果。超过阈值的旧式 XLS 会明确要求先转换为 XLSX/Parquet，不会冒险一次性读入。

这不是声明所有问题都线性，也不是任意非线性结构均能搜索到。当前仍使用有限的原语变异库；系数可辨识性、噪声模型、分组验证、ODE 与因果语义均需后续机制检验。题目文字在此入口作为背景保存，不被自动当成方程或约束。输入的单位、变量映射和所选行范围会随图假设保存到证据中。

最终留出可使用下节的验证表映射，也可继续上传单独 JSON 文件。JSON 字段引用编译后的 `x0`、`x1`…和 `y`，数值应已经是 SI 单位。留出点须在声明开发域内且不得与开发点/探针重叠；不能直接把原始厘米/分钟数值冒充换算后的量。

## 冻结后用验证表审计

1. 等待页面显示“候选已冻结”。未冻结时，验证字段接口和表格审计入口均不可用。
2. 在上方上传验证表或选择当前表格，展开“用当前表格做留出审计”。设置验证起始行，再点击“读取验证表字段”。
3. 系统固定从起始行起最多 256 行的数值字段快照。页面明确显示来源总行数和快照范围；后续编辑、替换当前表格不改变该快照。要选其他范围，重新读取字段，旧快照令牌随即失效。
4. 为冻结图的每个输入、目标选择对应列及其原始单位。下拉选项只包含量纲相容的已支持单位，例如时间允许秒/分钟/小时，不允许公斤。不同节点不能复用同一列，疑似编号不可作为测量值。
5. 核对验证行数、SI 数值约定和数据来源，点击“映射并执行只读审计”。单位换算后仍执行原有的开发重叠、重复验证点、范围及有限性检查；不拟合参数，不改变阈值，不把失败反馈送回搜索。

例如开发图使用秒和米，验证表可使用分钟和厘米，分别乘 60 和 0.01 后再评估。自行上传的数学图如果域、训练样本或阈值用的是厘米等非 SI 数值，不适用这个映射入口，不能靠勾选确认掩盖尺度错误。当前不支持带偏移的温标、任意复合单位以及输入节点直接兼作输出的表格映射；后者需要独立观测节点或继续使用 JSON。

`evidence/heldout_mapping.json` 保存冻结模型指纹、快照令牌、来源总行数、实际行范围、列/节点映射、单位和转换因子，并可从页面下载“验证表映射”。转换后的数值仍保存于 `heldout_input.json`，供追溯。快照是本地数据一致性保障，不证明采样独立、来源可信或未被人工选模使用；登记仍只阻止同一研究内的精确 SI 输入点重复消费。

## 使用流程

1. 选择开发实验 JSON，或点击“载入合成开发示例”。开发文件格式为 `mathmodel.graph-search-bundle/v1`，不含留出数据；文件上限 256 KB。
2. 填写稳定研究标识，例如 `cooling_study_01`，点击“运行通用搜索”。后台运行时可以查询状态或取消。
3. 页面分别显示开发搜索、冻结快照和留出审计。开发候选按照“Pareto 集中节点最少 → 开发 RMSE 最小 → 指纹排序”的固定规则选定；没有候选通过时，不开放留出入口。
4. 候选的结构、参数、阈值和证据快照保存后，留出控件才启用。选择验证表映射，或提交 `mathmodel.scalar-holdout/v1` 样本并点击“执行只读留出审计”。该阶段不拟合参数，不将结果回传搜索。
5. 下载论证报告、开发证据、冻结模型、留出证据及产物清单。运行结束不表示模型正确；检查失败、计算未完成和通过有限检查会分别展示。

可用 [开发示例](../examples/graph_search_scalar.json) 和 [留出示例](../examples/graph_search_heldout.json) 学习流程。它们是已经公开的合成数据，不是独立效果基准。第二次使用相同研究标识和留出输入会被拒绝；更换标识也不会使旧数据真正独立。

任意题面到可执行图的自动绑定仍未完成。表格入口会生成开发图和契约，其他复杂模型仍需显式变量、单位、区间、训练样本/性质和数值预算；不支持将一段任意 Python 或题目文本直接当可执行程序。支持的标量原语与文件规范见 [数学图搜索](graph_search.md)。多策略同预算对照目前仍在命令行，不在这个单模型网页面板中。

## 存储与执行边界

- 产物在 `workspace/graph_lab_runs/<run_id>/`，持久验证使用记录在 `workspace/confirmation/usage.sqlite3`。登记库不是可删除缓存；已有验证记录不会因取消、超时或新建运行而释放。
- 请求通过会话及不可预测运行 ID 绑定。下载接口只接受固定产物名称，不接受本地文件路径；响应不缓存。页面中的模型字段按文本转义，不作为 HTML 或代码执行。
- 每个服务进程最多同时执行两个实验，每个会话一次运行一个；底层数值 worker 仍有独立资源限制。多进程之间没有统一任务配额，资源隔离也不等同于文件/网络权限沙箱。
- 最多保留 32 个内存运行句柄；达到上限时淘汰旧的非运行句柄，但不删除其证据文件。服务器重启后会话句柄不恢复，文件和 SQLite 使用记录仍保留。浏览器刷新可恢复同一标签页最近的有效运行。
- `PUBLIC_MODE=1` 时此功能禁用。当前仅面向可信本地使用，不适用于直接提供多用户公网计算服务。
- 无真实模型 API 请求；仍不能证明题意正确、样本独立、因果成立或整个连续域无反例。前端显示做六位有效数字格式化，下载证据保留原始数值。
