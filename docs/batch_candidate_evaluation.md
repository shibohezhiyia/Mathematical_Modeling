# 批量候选评价

`core.batch_candidate_evaluation.evaluate_candidate_batch` 是一个受预算约束的编排层，用于结构相近的候选模型：

- 同一 `feature_key` 的候选只构建一次共享特征视图；
- 每个候选仍独立调用评价器，结果不会相互覆盖；
- 只把有限的状态、数值指标和诊断摘要写入反馈，原始预测、输入和完整 traceback 不会自动发送给模型；
- `retryable` 只产生带退避上限的重试计划，不在请求内隐藏重试，也不会把重试当成通过；
- 该层不授予执行权限、不替代类型/单位/资源/安全验证。

评价器应当是受信任的应用代码；任何生成代码必须先经过 `solver_worker` 等受监督执行入口。
