# 建模概念库

`ConceptLibrary` 建立在内容寻址的 `ExperienceStore` 之上，保存的是可迁移的建模概念，不是某一道题的最终答案。一个概念包括：

- 机制标签和自然语言陈述；
- 一个或多个最小原语实现；
- 适用条件和失败条件；
- 已发现的反例和可追溯的验证引用。

检索结果始终带有 `seed_only=true` 和 `requires_current_validation=true`。即使概念已经在旧任务上通过复现、反例和安全检查，当前题目仍需重新做类型、单位、资源、留出和反例验证。

遇到反例时使用 `revise_with_counterexample()` 写入新的 provisional 版本；旧的内容寻址对象不被覆盖，已验证对象也不会被静默修改。这使经验能够积累失败条件，而不会把历史错误传播成硬模板。
