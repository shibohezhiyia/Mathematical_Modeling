# 参数不确定性（Bootstrap 初版）

`bootstrap_parameter_uncertainty` 对观测索引有放回重采样，并调用同一个拟合器，报告每个参数的经验均值、标准差、5%/50%/95% 分位数、范围和拟合失败记录。`profile_likelihood_uncertainty` 在显式给定的一维参数网格上评估有限目标函数，并返回有界 level-set 区间。

它回答的是“在当前样本和当前拟合流程下，参数是否稳定”，不回答“参数的真实后验是什么”。失败、参数 schema 改变、成功重复不足和预算耗尽都保留为未评估/不充分状态；系统不会用均值或零方差填补缺失证据。使用时应配合独立留出、局部可辨识性和结构候选集合评估。
