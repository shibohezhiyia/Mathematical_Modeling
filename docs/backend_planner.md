# 规模感知执行路线

`core.backend_planner.plan_backend` 把已经通过数学契约校验的 IR 节点转换为一个受限执行计划。它只回答“应该走哪个可信后端、资源估算是否超限”，不会执行表达式、改变目标函数或把近似结果升级为证明。

计划会读取变量数、时间/样本点数和矩阵单元数：

- 已接入受控 worker 的 ODE、NLP 和标量图走 `trusted_worker`；
- 其他已注册数学结构走 `trusted_backend_api`，仍须使用各自的结构化契约；
- 未验证、没有求解器或规模超过上限的节点走 `defer`，并保留原因；
- 所有计划都明确 `arbitrary_code_allowed=false`。

这层是执行路由，不是可执行性证明。它不能替代量纲、边界、收敛、留出数据或独立复算检查。规模估算是保守上限，未知字段不会被猜成可执行规模。
