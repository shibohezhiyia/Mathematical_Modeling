# 数据来源与污染审计

`build_source_ledger` 为每个数据源记录 HTTPS/本地来源、内容 SHA-256、所有者、许可和授权状态，并暴露重复内容指纹。`content_shingle_digests` 生成有界归一化词片段指纹而不保留原文；`audit_contamination` 同时检查精确摘要和词片段重叠。它不能证明语义等价或排除模型记忆，仍需要外部复核。

URI 仅允许 HTTPS 或本地 `file://`；不接受明文 HTTP、嵌入式用户名/密码、控制字符、超长地址或远程文件主机。认证头/令牌必须通过带外配置提供。URI 格式合规不等于网页内容真实、许可有效或来源独立。
