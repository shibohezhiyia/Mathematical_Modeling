# 未闭合系统的竞争解释筛查

`core/unclosed_state_competition.py` 用于处理一个常见误判：残差有记忆时，不能直接宣布“存在隐变量”。它在开发数据窗口内并列检查：

- 滞后/潜状态信号；
- 外部输入信号（只有传入外部输入时才评估）；
- 异方差观测信号；
- 非平稳或机制切换信号；
- 函数库不足或数值失配的整体尺度信号。

输出是带证据的筛查候选和近似并列候选。分数不是概率，排序不是因果发现，也不授权修改 IR、硬约束或最终测试集。只有在候选竞争、独立留出轨迹、观测模型和可辨识性检查都支持时，才可以进入后续结构搜索；没有这些证据时仍应保留“未判定”。

该模块不把自产数据当作现实证据，也不替代 SINDy、延迟嵌入或物理观测。它的作用是阻止“高噪声 = 隐变量”的自动误报，并为下一步选择 `compare_noise_models`、`compare_memory_models`、`check_observations` 等受限路线提供依据。
