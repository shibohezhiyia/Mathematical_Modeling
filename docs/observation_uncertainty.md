# 观测与数据处理不确定性

`assess_observation_uncertainty` 要求每条记录绑定观测实体、处理分支、数值和统一单位，按观测实体、处理分支、观测×处理交互和处理单元内波动分解经验方差。可选的 `observation_noise_variance` 只作为显式噪声元数据记录，不会被系统擅自从经验残差中扣除。单次观测会标为 `partial`，混合单位、非有限值或负噪声方差直接拒绝。

结果是当前重复观测设计下的经验方差记账，不是测量误差模型、后验分布或置信区间；不平衡设计保留分解残差，不能把各项当作独立分数相加。它可以作为四层不确定性传播中的观测层输入，但不会自动改变模型参数。
