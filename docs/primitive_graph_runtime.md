# 类型化原语图运行时

`core.primitive_graph_runtime.execute_primitive_graph` 提供一条不解析生成代码的
受限执行路径。它先调用 `validate_primitive_graph`，再按依赖拓扑计算变量、常量、
观测和有限代数原语（加减乘除、幂、绝对值、指数、对数、正余弦）。输入只能通过
显式 `bindings` 提供，数组有元素数和有限值限制。

尚未闭合的 `unknown_mechanism`、潜变量、微分、事件、优化和图节点会被明确拒绝，
不会被当成数值答案。因而该运行时是动态编译链的一块安全执行基础，不是任意题面的
通用求解器；上层仍需补齐变量角色、单位、边界、目标和独立验证。
