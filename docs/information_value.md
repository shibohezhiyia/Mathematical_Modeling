# 主动澄清的信息价值

`estimate_question_information_gain` 在给定候选权重和答案—候选分区时，计算熵的期望下降量，并按“信息增益 / 声明成本”排序问题。每个问题可提供正的有限 `cost`；省略时为单位成本。它会显式保留未覆盖候选分支，并拒绝答案分区重叠或引用未知候选。

结果同时保留 `expected_information_gain_bits`、`cost` 和 `gain_per_cost`，因此调用方可以改用纯信息增益或其他经过预注册的决策规则，而无需重新计算分区。成本是数据采集、人工确认或可信仿真的相对预算，不是时间分布或概率。

结果是“条件于声明权重的期望信息增益”，不是现实世界后验概率，也不会自动替用户选择答案。用户不回答时，原有多假设结果仍然保留。

语义假设界面的 `rank_questions(..., options_by_question=...)` 会在选项能组成不重叠分区时附加同一指标；选项重叠或引用不完整时只返回 `not_assessed` 原因，并继续保留分歧×成本启发式排序。
