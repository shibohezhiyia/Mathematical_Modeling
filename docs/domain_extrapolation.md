# 域外反证检查

`assess_domain_extrapolation` 在题目声明域和一个有界扩展域上使用同一确定性探针集合，分别检查：

- 是否出现非有限值或执行定义域错误；
- 是否违反已声明的输出上下界；
- 域外输出尺度是否相对域内放大超过阈值。

结果分为 `counterexample_found`、`domain_shift_signal` 和 `no_falsification_in_tested_extension`。域内拟合不会因为域外压力测试而被偷偷修改；域外失败也不等于现实世界定理，只表示当前模型在记录的扩展点上不稳定或违反声明性质。所有反例携带阶段、探针坐标和值，最多保留 32 条。

执行任意模型时仍应使用项目的进程/资源监督；该模块只定义有限检查协议，不提供操作系统级沙箱。
